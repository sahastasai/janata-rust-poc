# Web and mobile-width screen captures

These captures are release-build evidence for all seven Dioxus routes. Desktop
uses a 1280×900 Chromium viewport; mobile uses a 390×844 Chromium viewport.
Both use full-page capture against the local release build.

The mobile-width images are review mocks for the shared Dioxus/WebView UI. They
are not Android emulator or iOS simulator screenshots, and must not be cited as
device/native-feature validation. The manual mobile workflow must first produce
the platform artifacts before simulator/device captures can replace them.

Routes captured in both widths: Home, Discover, Feed, Connect, Profile,
Benchmarks, and Contributor docs.
